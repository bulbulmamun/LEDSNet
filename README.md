# LEDSNet
Lightweight Deep Learning Model for Arrhythmia Classification

LEDSNet_Trained_Model.ipynb loads the trained model parameters and evaluate the model performance on a sample test set from the MITBIH Arrhythmia dataset.

The 'Model_Train' folder contains the python code that was used to train the LEDSNet model. The folder also contains the output log and the trained parameters.
